# Glowup UI v0.1.0 — Public Preview

An open-source design skill for coding agents to build new interfaces or substantially transform existing apps while preserving functionality.

- One canonical Agent Skills payload with CREATE, TRANSFORM and scoped polish workflows.
- Dependency-free Node 20+ helpers for design direction, scaffolding, preservation checks and local visual inspection.
- Recoverable installation/removal for documented Claude Code, Codex and other agent discovery paths.
- Reproducible browser checks and independent paired-evaluation tooling.
- Patched demo, fixture and starter test dependencies (Vitest 4.1.12).

Requirements: an agent with file access and its own authentication; Node.js 20+ for helpers. Browser capture requires an available browser or optional Playwright. Current-preview native activation, design superiority and cost/speed advantages remain unverified. No fabricated benchmark scores or adoption claims.

Install from a reviewed checkout of https://github.com/avivgerz-hue/glowup-ui using the README. No npm publication is implied. MIT licensed. This is a preview, with incomplete cross-agent and application coverage.
