# Open-source skill landscape

Checked **28 October 2026** against current public repository READMEs, skill sources, repository manifests and official client documentation. Repository descriptions are positioning, not evidence of model quality. No stars, downloads or testimonials are used as quality scores. No third-party source, graphics or branding was copied.

| Project and source | Observable practice | Decision for Glowup UI |
|---|---|---|
| [Impeccable](https://github.com/pbakaus/impeccable), [skill source](https://github.com/pbakaus/impeccable/blob/main/skill/SKILL.src.md), Apache-2.0 | README leads with a concrete installer and named design operations. These projects demonstrate presentation/workflow choices. Whether those choices explain adoption or improve model output is a hypothesis; this research did not run their agents or rank their design quality.

## Official discovery and installation research

Reviewed current sources for [Codex roots](https://github.com/openai/codex/blob/main/codex-rs/ext/skills/src/host_roots.rs), [OpenCode](https://github.com/anomalyco/opencode/blob/dev/packages/web/src/content/docs/skills.mdx), [Gemini](https://github.com/google-gemini/gemini-cli/blob/main/docs/cli/skills.md), [Copilot](https://github.com/github/docs/blob/main/content/copilot/concepts/customizations/agent-skills.md), [VS Code](https://github.com/microsoft/vscode-docs/blob/main/docs/agent-customization/agent-skills.md), [Pi](https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/docs/skills.md), [Vibe](https://github.com/mistralai/mistral-vibe#skills-system), [Goose](https://github.com/block/goose/blob/main/documentation/docs/guides/context-engineering/using-skills.md), and [Roo](https://github.com/RooCodeInc/Roo-Code/blob/main/apps/docs/docs/features/skills.mdx). Metadata discovery and body loading are different operations; permissions/trust can suppress activation. A directory convention is not authenticated runtime proof.

Hosted Claude, Codex, Agent Skills specification and Antigravity documentation could not be fetched in this environment. The earlier Claude skill-development source path returned 404; it is not used as fresh verification. Official client repository sources were used where available. Antigravity remains unverified, with no guessed installer alias. See the [compatibility matrix](../compatibility.md).

The [standard skills CLI](https://github.com/vercel-labs/skills) currently requires Node 22.20+. Its [telemetry source](https://github.com/vercel-labs/skills/blob/main/src/telemetry.ts) supports `DISABLE_TELEMETRY`/`DO_NOT_TRACK`. We tested a project-only copy install with both set, and retain this as an optional path. The primary quick start uses Glowup's own installer from the immutable published GitHub tag: one command, Node 20+ and Git, no added analytics or npm publication claim.

## What changed because of this research

Lead with brand, genuine examples and one tested command. Explain CREATE/TRANSFORM/REFINE in task language. Label each demonstration's provenance near its images. Keep compatibility evidence granular. Offer a short roadmap, actionable issue forms and an installer fallback. Preserve the concise canonical skill and avoid speculative design rewrites. No claim of proven design superiority is justified by these sources.
