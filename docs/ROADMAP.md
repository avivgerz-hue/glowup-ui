# Roadmap

A short list of work to validate, not capabilities already shipped:

1. Complete authenticated native activation tests, then matched CREATE/TRANSFORM trials with independent visual review.
2. Collect user-submitted examples with reproducible briefs, fictional/public data and clear permission to share screenshots.
3. Verify additional native agents from current official conventions; keep documented paths distinct from runtime proof.
4. Improve recipes from observed implementation failures, including accessibility and larger multi-page products.
5. Add framework examples only when a real use case justifies their maintenance cost.

No delivery dates, adoption targets or quality scores are promised. See [contributing](../CONTRIBUTING.md) for focused proposals.
