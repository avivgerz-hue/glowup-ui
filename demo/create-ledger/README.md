# Margin — CREATE example

A dependency-free, local finance workspace built in this maintainer-directed Codex session after explicitly reading Glowup UI's CREATE and finance-composition guidance. It is an illustrative implementation, not an authenticated native-CLI activation test or a controlled with/without-skill comparison.

Brief: three responsive views (overview, searchable/filterable activity, preferences), a balance trend, and a validated transaction dialog. Use fictional data, integer-cent calculations and browser-local persistence. Composition follows the finance recipe: one dominant balance/trend region, subordinate monthly context, aligned amounts and a shared navigation system. System fonts and original SVG geometry; no external service or bank connection.

Run `npm start` here, then open the local server on port 4188. `npm test` verifies the model; the showcase capture script exercises browser behavior and renders desktop/mobile views. This static app needs no bundler/build step. All sample people and transactions are fictional.
